# Saans World

Website for **Saans**, a student brand concept for a Marketing Management project: a hand block-printed loop scarf with a hidden, replaceable PM2.5 filter. *Style that breathes.*

Live site: https://ai-startup45.github.io/saans.world/

- `index.html`: the page (scroll-driven 3D product story and shop demo)
- `seq/`: pre-rendered 3D scene frames (`d*` desktop, `m*` phone)
- `img/`: poster images for each scene

Filtration level is a design target until lab-tested. The checkout is a demo.
